## `/principles`

<table>
<tr>
<td width="50%" valign="top">

### 01 — STREAM THE WORK

Don't make the user wait for a complete result when a useful partial result can already move forward.

</td>

### 02 — ATTACK THE CRITICAL PATH

</td>
