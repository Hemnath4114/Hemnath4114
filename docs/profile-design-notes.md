# Profile Design Notes

**Thesis:** Voice is still the fastest way to turn intent into action — build
for that, until something faster exists.

## Positioning
Domain-focused identity: Voice AI Engineer working across STT, TTS, LLM
orchestration, agentic systems, and real-time/latency engineering. No
employer or product names are referenced — the profile speaks to domain
expertise, not a specific job. Earlier full-stack work (ThinkNotes,
MoodTunes) is kept as lineage under `/foundations`, not the primary
identity.

## Visual system
- **Palette:** near-black surfaces (`#05070A`, `#07090D`, `#0D0D0E`) with a
  single accent family — amber/gold (`#E7B75C` → `#F2C878` → `#C98F3A`),
  used sparingly (signal lines, key nodes, status text, glow). Everything
  else is grayscale. Chosen over the earlier cyan/violet system to read as
  premium, cinematic, and studio/audio-coded (mixing-console amber) rather
  than generic "AI product" branding.
- **Type:** Inter for identity/explanatory copy, monospace (JetBrains Mono)
  for telemetry, labels, and system state.
- **Brand mark:** custom HM monogram — the M doubles as a waveform spike,
  tying the mark directly to the voice/audio domain. Available standalone
  at `assets/brand/hemnath-mark.svg` for reuse as an avatar/favicon.
- **Assets:** all custom SVG — `hero.svg` (identity, thesis, live waveform
  visualization), `voice-pipeline.svg` (generic voice AI systems
  architecture), `latency-pipeline.svg` (critical-path visual for TTFT /
  TTFA / E2E). No ASCII diagrams as the primary visual language.

## Information architecture
Hero → domain focus → profile → current focus → why-voice (personal
thesis) → architecture → principles → performance/latency → stack →
foundations (earlier work) → GitHub telemetry → contact.

## What was deliberately left out
Emoji-led headings, long biography paragraphs, flat logo walls, badge
overload, motivational quotes, unverified performance claims, and any
mention of current employer or product names.
