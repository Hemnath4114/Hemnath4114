# Profile Design Notes

**Thesis:** Make the system disappear between intent and experience.

## Positioning
Full-stack foundations → AI integration → Voice AI → LLM systems → Real-time
AI infrastructure → Latency + orchestration. The old MERN work is kept as
lineage (see `THINKNOTES` / `MOODTUNES` under `/selected-work`), not as the
primary identity.

## Visual system
- **Palette:** near-black/graphite surfaces (`#05070A`, `#0B0F14`, `#111827`)
  with semantic accents — cyan `#22D3EE` (live/active), violet `#8B5CF6`
  (reasoning/model layer), blue `#60A5FA` (data/infra).
- **Type:** Inter for identity/explanatory copy, monospace (JetBrains Mono)
  for telemetry, labels, and system state.
- **Assets:** all custom SVG — `hero.svg` (identity + status telemetry),
  `voice-architecture.svg` (flagship Lola system), `latency-pipeline.svg`
  (critical-path visual for TTFT / TTFA / E2E). No ASCII diagrams as the
  primary visual language.

## Information architecture
Hero → current signal → profile → domain map → flagship system (Lola) →
architecture → latency/performance → stack → selected work → GitHub
telemetry → contact. Highest-value signal is placed before conventional
stats and contact info.

## What was deliberately left out
Emoji-led headings, long biography paragraphs, flat logo walls, badge
overload, motivational quotes, and unverified performance claims.
