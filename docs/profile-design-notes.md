# Profile Design Notes

**Thesis:** Voice is still the fastest way to turn intent into action — build
for that, until something faster exists.

## Positioning
Domain-focused identity: Voice AI Engineer working across STT, TTS, LLM
orchestration, agentic systems, and real-time/latency engineering. No
employer or product names are referenced. Earlier full-stack work
(ThinkNotes, MoodTunes) is kept as lineage under "Earlier Work," not the
primary identity.

## Visual system
- **Palette:** near-black surfaces (`#05070A`, `#07090D`, `#0D0D0E`) with a
  single metallic accent family — chrome-white to steel to deep graphite-blue
  (`#F4F6F9` → `#B9C2D1` → `#5B637A`), used sparingly for signal lines, key
  nodes, and status text. Everything else is grayscale. Chosen for a cool,
  spatial-audio-hardware feel ("ultraspace") rather than a warm or
  saturated accent.
- **Type:** Inter for identity/explanatory copy, monospace (JetBrains Mono)
  for telemetry, labels, and system state.
- **Mark:** a minimal circle-and-waveform glyph — deliberately not
  letterform-based, so it reads as a voice/audio symbol on its own.
  Standalone at `assets/brand/hemnath-mark.svg`, also embedded in the hero.
- **Section headings:** plain words (About, Currently, Why Voice,
  Architecture, Principles, Performance, Stack, Earlier Work, GitHub) —
  no slash-command styling, for a more timeless, less "terminal cliché" feel.
- **Assets:** all custom SVG — `hero.svg` (identity + live waveform),
  `now-strip.svg` (current focus as a console/meter strip, replacing a
  static arrow diagram), `voice-pipeline.svg` (systems architecture),
  `latency-pipeline.svg` (TTFT / TTFA / E2E critical path).

## Information architecture
Hero → domain focus → About → Currently → Why Voice (personal thesis) →
Architecture → Principles → Performance/latency → Stack → Earlier Work →
GitHub → contact.

## What was deliberately left out
Emoji-led headings, long biography paragraphs, badge overload, motivational
quotes, unverified performance claims, employer/product names, and
letterform-only logos.
